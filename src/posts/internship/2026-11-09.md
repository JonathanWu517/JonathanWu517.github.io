## 工作内容

### 1. 入职与学习材料概览

入职晨昏线科技，研究方向涉及人形机器人运动控制、物理仿真、模仿学习与强化学习。  
本日精读材料《运动先验与强化学习算法》，围绕三种方法展开：

- DeepMimic
- AMP（Adversarial Motion Priors）
- GMP（Generative Motion Prior）

核心问题：仅靠任务奖励做 RL（Reinforcement Learning）时，策略可能“能完成目标但动作不自然”（如膝关节过度弯曲、身体晃动、手臂不协调、能耗过高等）。因此需要引入运动先验 MP（Motion Prior），用参考运动数据约束或引导策略。

### 2. 共同基础：为什么需要运动先验

- 运动数据来源常见有：MoCap（Motion Capture）、机器人遥操作数据、仿真生成轨迹
- MP（Motion Prior）通常不取代 RL，而是通过改奖励、观测或参考目标，让策略更容易学到符合运动规律的行为
- 三种方法都可与 PPO（Proximal Policy Optimization）结合，差别在于“运动监督信号怎么构造”

一句话对比（材料核心）：

| 方法 | 监督信号在问什么 |
|------|------------------|
| DeepMimic | 如何跟踪某个参考动作？ |
| AMP（Adversarial Motion Priors） | 生成运动是否符合参考运动分布？ |
| GMP（Generative Motion Prior） | 在当前状态和指令下，下一步自然运动是什么？ |

### 3. DeepMimic：显式参考运动跟踪

- 论文：Peng 等人，SIGGRAPH 2018；目标是让物理角色用 RL 复现参考运动，同时能根据真实物理状态调整，而不是机械播放动画
- 训练时从参考片段取目标姿态/速度，策略输出控制；仿真执行后比较实际与参考，得到模仿奖励
- 模仿奖励常拆成多项：姿态、速度、末端执行器、质心等误差
- 工程关键点：
  - Phase：参考动作时间进度/周期相位
  - RSI（Reference State Initialization）：从参考动作不同时间点初始化，避免只会从第一帧开练
  - Early Termination：严重偏离或失败时提前终止，减少无效采样
- 优势：监督直观，适合有明确时序的高动态技能（如后空翻）
- 局限：需要时间对齐，奖励权重敏感，多技能切换需额外设计

### 4. AMP：对抗式运动先验

- 论文：Peng 等人，SIGGRAPH 2021；不要求逐帧跟踪某一条指定轨迹
- 训练判别器 Discriminator，区分参考运动与策略生成运动；把判别器分数转成风格奖励 Style Reward，让策略运动落在参考分布附近
- 判别器输入通常是相邻状态的运动特征（根节点速度、局部关节旋转/速度、关键部位位置等），从而同时看姿态与运动变化
- 注意点（材料特别强调）：
  - 判别器输出是实数分数，末尾不要随便加 Sigmoid 当概率用
  - 使用 Least-Squares 判别损失；Gradient Penalty 与 WGAN-GP 的“梯度范数约束到 1”不能混为一谈
  - Style Reward 是围绕目标标签 +1 的非负函数，不是“分数越大奖励必然越大”
  - 任务奖励决定“做什么”，风格奖励约束“怎么做”
  - 判别器有独立的 Replay Buffer，不要和 PPO 的 On-policy Rollout Buffer 混为一谈
- 优势：无需逐帧指定参考；可从多片段学风格；任务与风格相对解耦
- 局限：对抗训练可能不稳；风格奖励是标量，难指出具体关节该怎么改

### 5. GMP：生成式运动先验

- 相关工作：《Natural Humanoid Robot Locomotion with Generative Motion Prior》；用生成模型学习运动数据的条件分布
- 流程概要：当前运动状态 + 速度指令 → 生成未来参考运动 → RL 策略学习跟踪这些参考
- 与 AMP 不同：AMP 给风格评分；GMP 直接提供可跟踪的运动量（如关节状态、关键点位置）
- 数据侧需要 Motion Retargeting（运动重定向）：把人体 MoCap 映射到机器人形态，并检查关节限位、足底接触、穿透、坐标系与采样一致性
- 模型侧常见结构：
  - CVAE（Conditional Variational Autoencoder）：学“给定当前帧，下一帧怎么走”
  - Autoregressive（自回归）多步生成：可拉长时域，但误差可能累积
  - Command Encoder：把目标速度指令编进潜变量，再交给冻结的 Motion Decoder
- 训练阶段通常：离线训生成模型 → PPO 阶段冻结生成模型，主要更新控制策略与价值网络
- 优势：提供细粒度未来参考；可响应速度指令；生成模型与 PPO 分阶段，避免在线对抗
- 局限：依赖高质量重定向数据；生成结果不一定天然满足动力学；分布外指令泛化受限

### 6. 系统比较与工程注意（摘记）

同一任务“1.0 m/s 向前走”时：

- DeepMimic：按参考步态相位取姿态/速度并跟踪
- AMP：判别器比较运动转移是否像参考步态分布，同时做速度任务
- GMP：按当前状态 + 1.0 m/s 指令生成未来参考，再跟踪关节/关键点

工程通用模块：Motion Dataset、Retargeting、Observation Builder、Policy/Value、Reward、Physics Engine。  
常见错误包括：坐标系不一致、人体关节角直接复制给机器人、只看总奖励不拆 Task / Style / Guidance、AMP 误用 Sigmoid、GMP 只验单步不验多步自回归误差等。

## 收获与思考

1. 运动先验的本质，是把参考运动数据变成策略可用的监督信号；三种方法不是简单“谁替代谁”，而是不同构造方式。
2. 记忆口诀：DeepMimic 管“跟踪指定动作”，AMP 管“像不像运动风格”，GMP 管“按状态和指令生成未来自然运动”。
3. 后续学习应回到原论文核对状态定义、奖励权重、归一化与训练时序；开源复现也可能有实现差异。
